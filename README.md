# Anlamsız Derin Felsefe Makinesi

Bu repository, insanlığın en büyük sorularına cevap vermek üzere tasarlanmıştır.

Ama aslında cevap vermez.

Sadece çok ciddi görünen, tamamen saçma sapan felsefi cümleler üretir.

## Nasıl Çalışır?

```bash
python felsefe.py
```

Çalıştırırsın. Bir cümle çıkar. Okursun. Hiçbir şey anlamazsın. Mutlu olursun.

## Neden Var?

Çünkü dünyada yeterince anlamsız şey yoktu. Biz de bir tane daha ekledik.

## Uyarı

Bu makine gerçek felsefe üretmez. Eğer anladığını düşünüyorsan, yanılıyorsun.
